Featured cloud lab

Private EC2 access on AWS

I configured SSH access to a Linux EC2 instance in a private subnet without assigning the instance a public IP address.

What I built

I used an EC2 Instance Connect Endpoint to reach the instance. The instance security group allowed inbound SSH on TCP port 22 from the endpoint’s security group.

The lab gave me practice with subnet placement, private access and security group rules.
